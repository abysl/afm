# AFM Bevy

This is the first Bevy feature-flow shell for Abysl File Manager.

Enter with `devenv shell`, then use `run-bevy` to open the AFM window,
`test-bevy` for Cargo tests, or `release-bevy` for a local release build. The
pinned devenv lock supplies Rust and the Linux audio, windowing, input, Vulkan,
and Wayland/X11 runtime libraries needed by Bevy.
